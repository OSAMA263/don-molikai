# Don Molikai

Frontend website for Don Molikai, a Spanish food brand from Navarra. It showcases the brand's products with smooth animations, tells the story of how the brand started, and gives visitors the contact information they need.

**Live demo:** [don-molikai.vercel.app](https://don-molikai.vercel.app)

## Features

- **Products:** browse the full product range in an animated, carousel-based showcase
- **Our story:** the history of the brand and how it began, presented section by section
- **Animations:** scroll-based reveals, smooth scrolling, and animated transitions throughout the site
- **Contact:** contact information so customers can easily reach the brand
- **Responsive:** designed to work across mobile, tablet, and desktop

## Tech Stack

Next.js, React, TypeScript, Tailwind CSS, Framer Motion, Lenis, Embla Carousel

## Run Locally

```bash
git clone https://github.com/OSAMA263/don-molikai.git
cd don-molikai
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
